# Changelog

All notable changes to NetBar are documented here.

## 1.0.5 - 2026-11-20

- Move the status display up by one point.

## 1.0.4 - 2026-11-20

- Increase the menu bar text size to 11 points.

## 1.0.3 - 2026-11-20

- Vertically center the two-line status display.
- Increase menu bar text size by one point.

## 1.0.2 - 2026-11-20

- Show upload and download on separate lines with upload on top.
- Reduce menu bar text size to fit the two-line layout.

## 1.0.1 - 2026-11-20

- Keep menu bar fields at fixed character widths to prevent layout jitter.
- Use a fully monospaced font for the menu bar title.

## 1.0.0 - 2026-11-20

- Initial source release.
- Menu bar display for download rate, upload rate, CPU usage, and memory usage.
- Native AppKit implementation with universal Intel and Apple Silicon builds.
- Local and notarized release workflows.
