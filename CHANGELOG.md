# Changelog

All notable changes to NetBar are documented here.

## 1.0.1 - 2026-11-20

- Keep menu bar fields at fixed character widths to prevent layout jitter.
- Use a fully monospaced font for the menu bar title.

## 1.0.0 - 2026-11-20

- Initial source release.
- Menu bar display for download rate, upload rate, CPU usage, and memory usage.
- Native AppKit implementation with universal Intel and Apple Silicon builds.
- Local and notarized release workflows.
